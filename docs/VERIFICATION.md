## 性能快照

测试环境：Windows 11 x64（Build 26200）、Intel Core i7-14650HX、15.7 GiB 内存。界面场景使用 `scripts/measure.ps1` 各连续测量 5 次；20 分组后台压力场景测量 7 次，并使用 3 秒 CPU 采样窗口。

| 场景 | 中位数 | P95 | 最大工作集 | 最大私有内存 | 1 秒最大归一化 CPU |
|---|---:|---:|---:|---:|---:|
| 1 分组、0 项，后台驻留 | 105 ms | 171 ms | 13.84 MiB | 1.99 MiB | 0.065% |
| 1 分组、0 项，竖向 Dock 显示 | 151 ms | 244 ms | 19.41 MiB | 2.46 MiB | 0.065% |
| 20 分组、500 项，后台驻留 | 115 ms | 187 ms | 15.67 MiB | 2.54 MiB | 0.043%（3 秒采样） |
| 20 分组、500 项，竖向 Dock 显示 | 149 ms | 208 ms | 21.48 MiB | 2.90 MiB | 0.195% |
| 20 分组、500 项，打开中央内容窗口 | 303 ms | 345 ms | 22.12 MiB | 3.44 MiB | 0.456% |

压力配置将 500 项全部放在当前分组，并包含一个断开的 UNC 目标。后台场景等待隐藏的常驻窗口就绪；分组栏场景显示右缘透明栏；内容场景再选择首个分组并显示中央内容窗口。就绪时间包含 PowerShell `Start-Process` 和轮询开销，因此是端到端近似值，不是进程内部埋点。内存与 CPU 在就绪后的 1 秒窗口采样；表格资源值取 7 次样本中的最大值，并非进程生命周期峰值。CPU ≤ 0.1% 的 MVP 门槛针对后台隐藏驻留；可见界面使用更快检测频率，打开 500 项时还包含异步 Shell 图标提取。

## 人工检查

- 右缘只显示窄幅中性半透明圆角 Dock；分组文件夹图标直接单列排列，右上角是小型实心图钉，没有“分组”标题及底部新增按钮

- 中央内容窗口默认隐藏；点击分组后在当前屏幕居中显示，切组复用原窗口，右上角关闭按钮只隐藏内容窗口

- 启动目标或关闭面板后进程继续驻留托盘；托盘“退出”后进程结束且锁文件释放
