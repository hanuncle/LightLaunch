# LightLaunch 项目立项书

## 1. 项目定义

- 工作名称：LightLaunch（可在发布前更名）
- 项目目录：`E:\project\desktop_launch`
- 产品类型：Windows 本地应用分组启动器
- 核心用户流程：后台驻留 → 鼠标触及屏幕右缘快速展开透明分组栏 → 点击一个或多个分组打开独立桌面围栏 → 添加或拖入应用快捷项 → 双击启动 → 未固定界面各自收回
- 第一优先级：轻量化

## 2. 成功标准

MVP 完成时，用户能够：

1. 创建“游戏开发”等分组。
2. 向分组添加普通 EXE、Windows 快捷方式和文件夹。
3. 看到目标名称及图标，并可双击启动。
4. 重命名、移动或移除启动项。
5. 从托盘退出并重新启动程序后，数据保持一致。
6. 删除分组或启动项时，不影响磁盘上的原始文件。
7. 启动目标或关闭面板后，程序驻留通知区域；从托盘可恢复或明确退出。
8. 从屏幕工作区右缘快速唤出面板，离开后快速收回；需要持续显示时可点击右上角小图钉固定。
9. 默认只看到 macOS Dock 风格的窄幅半透明圆角托盘和带 2×2 图标预览的单列分组图标；点击分组打开该组独立的 openFences 风格围栏，可同时打开多个。
10. 每个围栏都有独立图钉和关闭按钮，可在桌面自由拖动并从四边或四角调整大小；围栏固定状态与 Dock、其他围栏互不影响。
11. 通过已打开内容区的右键空白处或拖放添加内容。

## 3. MVP 范围

必须包含：

- 分组的新建、重命名和删除
- 启动项的添加、重命名、移动和移除
- 带前 4 个应用图标预览的单列可滚动 Dock 分组栏
- 默认隐藏、按分组独立创建、可多开、拖动、缩放、固定及关闭的桌面围栏窗口
- EXE、LNK、脚本、URL 文件和文件夹启动
- 本地持久化、损坏恢复和单实例保护
- 中文路径、空格路径及高 DPI 支持
- 系统托盘驻留、隐藏/恢复、明确退出及 Explorer 重启后图标恢复
- 右缘快速检测、自动展开/收回、运行期图钉按钮、可滚动 Dock 分组栏和文件拖入

明确不包含：

- 搜索引擎、标签和嵌套分组
- 自动扫描已安装应用
- 全局热键和开机启动
- 云同步、账号、网络请求和遥测
- 插件、主题系统和动画框架
- CLaunch 配置导入
- 安装器和自动更新

## 4. 技术方案

- 语言：C++20
- UI：原生 Win32 色键透明宿主、半透明圆角竖向 Dock、自绘单列分组图标、每组独立的深色半透明围栏、ListView 和 ImageList
- 系统集成：Windows Shell API
- 构建：CMake + MSVC x64 Release
- 运行库：静态 CRT `/MT`
- 数据：UTF-16 INI，无第三方解析库
- 配置位置：`%LOCALAPPDATA%\LightLaunch\config.ini`
- 保存策略：临时文件写入完成后原子替换，并保留 `.bak`
- 进程模型：单实例；启动后隐藏驻留，通过右缘或托盘展开；每个分组围栏按需创建且可同时显示；启动目标、未固定时离开对应界面或关闭后再次隐藏，从托盘“退出”才结束进程
- 临时界面状态：Dock 和各围栏的固定、位置、尺寸状态不写入配置，程序重启后默认未固定且围栏隐藏

## 5. 轻量化验收门槛

基准环境为 Windows 11 x64、SSD，最多 20 个分组和 500 个启动项。

| 指标 | MVP 门槛 | 理想目标 |
|---|---:|---:|
| Release EXE | ≤ 3 MiB | ≤ 1.5 MiB |
| 可交互窗口启动时间 P95 | ≤ 350 ms | ≤ 200 ms |
| 空闲工作集 | ≤ 25 MiB | ≤ 18 MiB |
| 空闲私有内存 | ≤ 15 MiB | ≤ 8 MiB |
| 后台隐藏驻留 CPU | ≤ 0.1% | 长期显示 0% |
| 网络连接 | 0 | 0 |
| 从托盘退出后的后台进程 | 0 | 0 |

当前 Release 构建的复测结果（界面场景 5 次，20 分组后台压力场景 7 次）：

- EXE：225.5 KiB（230,912 bytes）
- 空配置后台驻留：就绪中位数 105 ms，P95 171 ms；最大采样工作集 13.84 MiB，最大采样私有内存 1.99 MiB；1 秒采样最大归一化 CPU 0.065%
- 空配置竖向 Dock：就绪中位数 151 ms，P95 244 ms；最大采样工作集 19.41 MiB，最大采样私有内存 2.46 MiB
- 压力配置（20 分组、500 项）后台驻留：就绪中位数 115 ms，P95 187 ms；最大采样工作集 15.67 MiB，最大采样私有内存 2.54 MiB；3 秒采样最大归一化 CPU 0.043%
- 同一压力配置显示竖向 Dock：就绪中位数 149 ms，P95 208 ms；最大采样工作集 21.48 MiB，最大采样私有内存 2.90 MiB
- 同一压力配置打开 500 项中央内容窗口：就绪中位数 303 ms，P95 345 ms；最大采样工作集 22.12 MiB，最大采样私有内存 3.44 MiB
- 4 次连续 UI 冒烟实测：右缘唤出 40–67 ms、鼠标移出收回 121–156 ms；Shell 图标后台加载，慢路径不阻塞首次显示和分组切换

测试环境为 Windows 11 x64（Build 26200）、Intel Core i7-14650HX、15.7 GiB 内存。完整验证记录见 `docs/VERIFICATION.md`。

## 6. 阶段计划

### M0：立项与骨架

- 确认范围和性能门槛
- 建立 CMake、MSVC、测试与文档结构

### M1：可用 MVP

- 完成分组、启动项、Shell 图标和启动
- 完成本地配置与备份恢复
- 完成单实例和高 DPI 支持
- 完成系统托盘驻留、隐藏/恢复和明确退出
- 完成右缘竖向 Dock 极速唤出/收回、右上角小图钉、2×2 预览单列分组图标、多围栏并存、独立固定、自由拖动缩放、关闭和拖放添加
- 产出便携单 EXE

### M2：日常使用增强

- 拖动排序
- 启动参数、工作目录编辑
- 失效路径重新定位
- 键盘导航完善

### M3：发布准备

- 多显示器与 100%/150%/200% DPI 验证
- 500 项压力与 GDI/句柄泄漏测试
- 应用图标、版本资源和代码签名方案
- 可选 ZIP 或安装器

## 7. 风险与约束

- Shell 图标在后台提取；按当前 Dock 滚动视口分批提取前 4 个预览图标并少量预取相邻分组，详细内容只在打开分组时加载，失效路径或网络位置不会阻塞窗口首次显示。
- Win32 原生界面视觉较朴素；MVP 不为视觉效果引入大型 UI 框架。
- 未签名程序可能触发 SmartScreen 信誉提示；不通过压缩壳规避。
- 配置条目只保存目标引用，绝不管理或删除原始应用文件。
- 托盘驻留会保留一个 LightLaunch 进程；从托盘明确退出后进程和配置锁都会释放。
